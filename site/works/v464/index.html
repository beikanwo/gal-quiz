故事简介

夏。\
附近坐落着破火山口湖，被自然环绕的乡下村庄──「高千穂」（たかちほ）村。\
在那个高千穂村，主人公发觉了正茫然仰望天空的自己。\
\
\
──失忆。\
\
\
有关过去的记忆已经丧失了。\
奇怪的是，明明是白天，天空却呈现出仿佛将黄昏与日出融合在一起的、\
奇怪的颜色。\
\
\
被一位自称是表姐的女性带着，主人公将在「橘高」家寄宿。\
那个家里，有着美丽的4姐妹。\
\
\
短暂的，平稳的日常。\
\
\
──不久，悲伤的事件拉开了帷幕。
