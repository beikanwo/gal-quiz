故事简介

公元2034年。\
名为“铁鬼”的金属生命体出现，大半人类被驱逐殆尽。\
金属制品也变得无法使用，连文明与技术都随之丧失。\
只有在铁鬼活动缓慢的“间隙”里，人类才得以幸存。\
\
那之后过了1000年。\
一位英雄，打倒了作为铁鬼核心的存在之一。\
\
『赌上人类命运的战斗，在100天前，结束了』\
『所以，从现在开始的故事里，只剩下“希望”和“幸福”了』

故事的舞台是被称为“坎特”的国家。\
总人口800人的能力者们所生活的，和风文明。\
战斗结束了，然而。\
为了生存而持续战斗的坎特的人们，失去了个性与文化。\
一般居民全都只是戴着狐狸面具的「不是任何人的存在」而已。\
\
「“希望”和“幸福”，是什么？」\
「我们除了战斗之外该做些什么，完全，不知道」

就在那时，一位从1000年前起就处于冷冻睡眠状态的青年被发掘了出来。\
青年——他，将成为这个故事的主人公。\
\
他，或许是因为冷冻睡眠的弊端而失去了记忆。\
虽然不了解自己的事情，但是，却拥有文明与文化等方面的知识。\
\
「能和我们约定，为这个世界创造出希望与幸福吗？」\
\
在宛如异世界的坎特醒来的主人公。\
以保障衣食住为交换，他被请求为坎特带来文化。\
\
他的故事，在赌上人类命运的战斗结束后才开始。

\
这是，讴歌古怪学园生活的故事。\
是关于咖啡店与货币经济的故事。\
是关于统治者所需的资质与努力的故事。\
是什么人都不是的一位少女，直到怀揣梦想的故事。\
\
然后——是关于“英雄”之死的真相，以及关于“他”真实身份的告白。
