故事简介

■□■故事■□■
“呼哈——！射了——！”
清晨的阳光从窗户照进来，上午9点的6叠大房间。
把精力都倾注在刚买的工口游戏上的我，把用完的纸巾扔进了垃圾桶。
虽然想再来一发……但11点就要面试了。
你问为什么在这么重要的日子，一大早还在玩工口游戏自慰？
呼……愚蠢的问题……
那是因为我，热爱工口游戏！！
没错，我今天参加的面试，就是工口游戏公司的招聘面试！
……话虽如此，我不会画画。
也不会写剧本，作曲更是绝对不行。
我拥有的，只有至今为止玩过的近千款工口游戏的知识，以及最重要的，对工口游戏的热情。
当然，我已经被很多公司淘汰了……
但今天绝对！无论如何！
要进工口游戏公司上班，我也要做工口游戏！
……于是，好不容易考上的公司“Flower”，竟然濒临倒闭！
下一部作品如果卖不出去就肯定会消失……或者说，连工资都发不出来了！
取而代之的是，员工全都是可爱的女孩子……
本以为如此，结果全是些性格古怪的人……
明明各自都有才能，但对工口的知识和热情却压倒性地不足！
由这样的员工制作的下一部作品，竟然是凌辱类作品！？
这样下去的话，好不容易入职的公司就要没了……！
但是，我不会输！我绝不会放弃！！
“为了能做出色情的工口游戏，我会加油的！！”

■□■登场角色■□■
●姬乃如月(姫乃 きさら)　（CV：佐藤雪）
笔名：樱莫那加
身高：160cm
三围：B87 / W55 / H86 E罩杯
工口游戏公司“Flower”的主原画。
这次是第三次担任原画。
也会发行同人志，是颇有人气的社团。
自尊心强，想到什么就说什么，连对社长都用平辈语气的强势女性。
原画速度受精神状态影响，心情好时画得快，低落时则极端缓慢。
此外，虽然能把脸画得很可爱，素描也还过得去，
但非常不擅长色情的构图、画面平衡和肉感描写。
简而言之，画出的画可爱但不色情。
“等一下，什么意思。你是在说我的画是负分对吧？”

●藤原桃花　（CV：御苑生芽衣）
笔名：弓木美优
身高：155cm
三围：B96 / W58 / H87 H罩杯
工口游戏公司“Flower”的剧本作家。
偶尔在BL杂志写短篇小说赚取收入，颇有人气。
性格沉稳我行我素，非常喜欢漂亮和可爱的东西。
放任不管的话经常一个人胡思乱想，
其内容大多关于可爱的女孩子。
剧本构成和角色描写很优秀，
但因为不懂性爱，会写出抽象又奇幻的色情场景。
此外，喜欢漂亮、可爱事物的性格带来麻烦，也不擅长描绘阴暗的故事和深刻的纠葛，
导致剧本整体弥漫着童话般的氛围。
“唔咕咕咕咕咕咕咕咕咕……男人……男人啊……男人……！”

●高坂伊织(高坂 伊織)　（CV：樱川未央）
笔名：伊织
身高：170cm
三围：B81 / W56 / H75 C罩杯
工口游戏公司“Flower”的图像师。
在数字画集系同人社团有不错的销量。
非常沉默，大多时候面无表情。
让人搞不清在想什么的女性。
沟通起来非常困难，
但女性员工们似乎即使她不说话也能明白她想说什么。
在角色和背景上色方面拥有高水平的涂色技巧，
但对于工口游戏重要的汁液（精液、爱液、汗水、唾液）和肉感表现等，煽动色情感的上色却完全不行。
“……嗯……是下流还是肮脏呢……”

●园野宁宁(園野 寧々)　（CV：此花）
笔名：园音
身高：145cm
三围：B68 / W54 / H71 AA罩杯
工口游戏公司“Flower”的社长兼营业兼导演兼脚本师。
为了节约而在公司会议室吃住。
外表娇小，但却是如假包换的成年女性，也是“Flower”最年长的人。
平时因为尺寸关系和员工的要求而穿着孩子气的服装，
有营业或外出办事时则会穿西装。
这是作为成年人的修养。
当然即使是S码也很大，所以松松垮垮的。
唯一在工口游戏方面有相应的知识和感性，但性格软弱无法指导大家。
也因为外表的关系，在公司内被当作吉祥物对待，
出去营业时也很难被认真对待。
“嘿嘿嘿——为了能发得出望月同学的工资，大家一起加油吧——！”
